## F4 Contact form

- `consultationForm` submit handler exists and is wired (contact.js:156). HTML5 `required` attributes present on inputs.
- CONFIRMED + FIXED: `country: countryOrigin()` at contact.js stored a Promise object, and `countryOrigin` never returned the country (`fetchGeolocationData` discarded `updateCountry`'s return). Fixed: made the submit handler async, made the fetch chain return `data.country`, `country: await countryOrigin()`.
- DOCUMENTED (not fixed): `fetchGeolocationData` calls `http://ip-api.com/json/` which is plain HTTP. On the HTTPS site this is mixed content and the request is blocked by the browser, so `country` will be null in production even though the code is now correct. Recommendation: switch to an HTTPS geo endpoint (e.g. ipapi.co) or drop the field. Flagged as a human decision since it changes an analytics dependency.
- Tidio chat: `<script src="//code.tidio.co/f1y79gyqdaoifsyjsg3va1jmuwklonpm.js">` in contact.html returns HTTP 404 from tidio's own CDN (verified `curl -sI` -> `HTTP/2 404`), so the chat widget has been dead in production. Removed the dead script tag; the tidio iframe manipulation block in contact.js (~line 455) is null-guarded and now dormant. If chat should exist, a new Tidio widget key is needed - flagged in decisions.

## F7 CONFIRMED + FIXED: DefinePlugin silently broke Firebase in some build environments

webpack pushed a manual `DefinePlugin` AFTER `Dotenv`, so `JSON.stringify(process.env.FIREBASE_*)` (read from the Node build process, often unset) overrode the real values dotenv-webpack injected from `.env`. Evidence: `WARNING in DefinePlugin: Conflicting values for 'process.env.FIREBASE_*'` x8 whenever `.env` existed, and bundles built without exported shell env got `undefined` config (fatal Firebase error, verified in browser).

Impact: CI gh-pages builds (workflow writes `.env` but never exports the vars) shipped broken Firebase config. Vercel worked only because its env lands in `process.env`.

Fix: removed the manual DefinePlugin block and set `systemvars: true` on Dotenv, which covers both `.env` files (CI/local) and real env vars (Vercel). Post-fix build: 0 DefinePlugin warnings, Firebase initializes in browser (verified: no console errors, config literal present in main.bundle.js).
